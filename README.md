# Gender Classification — SVM vs Random Forest

Сравнение двух классификаторов на реальных HR-данных.

## Описание

Датасет: [HR Analytics: Job Change of Data Scientists](https://www.kaggle.com/datasets/arashnic/hr-analytics-job-change-of-data-scientists)

Задача: бинарная классификация по признаку **пол (gender)** на основе анкетных данных соискателей.

Исходный набор содержит 19 158 записей и 14 признаков. После удаления строк с пропущенным значением `gender` осталось 14 650 записей. Целевой признак бинаризован: 0 — Male, 1 — Female/Other. Дисбаланс классов ~9:1 (Male ~90%), что потребовало `class_weight='balanced'` в обеих моделях.

## Модели

- **SVM** (метод опорных векторов, ядро RBF) — подбор гиперпараметров через `GridSearchCV` (kernel, C, gamma, decision_function_shape, shrinking)
- **Random Forest** — итеративный (coarse-to-fine) подбор гиперпараметров: сначала `max_features`, `max_depth`, `criterion`, затем `min_samples_split`, `min_samples_leaf`, `n_estimators`

## Результаты

| Модель        | Precision | Recall | F1     |
|---------------|-----------|--------|--------|
| SVM           | 0.16      | 0.52   | 0.24   |
| Random Forest | 0.17      | 0.48   | 0.25   |

Лучший классификатор по F1: **Random Forest**. SVM даёт чуть более высокий recall (лучше находит миноритарный класс), но Random Forest точнее (выше precision) и в целом даёт лучший баланс метрик.

Низкий precision у обеих моделей закономерен: при дисбалансе 9:1 даже взвешенные модели неизбежно дают ложные срабатывания — слишком мало примеров класса 1 для надёжного обучения.

### Важность признаков (Random Forest)

Наибольший вклад вносят специализация в гуманитарных науках (`major_discipline_Humanities`), принадлежность к конкретному городу (`city_city_103`) и индекс развития города (`city_development_index`) — то есть направление подготовки и географический контекст коррелируют с полом соискателя сильнее, чем количественные признаки вроде часов обучения или стажа.

## Выводы

1. Задача сводится к предсказанию пола соискателя по демографическим, образовательным и профессиональным признакам. Дисбаланс ~9:1 — типичная проблема HR-данных в IT-сфере.
2. Оба классификатора показывают умеренные результаты, типичные для сильно несбалансированных данных: F1 в районе 0.24–0.25.
3. Random Forest с полным coarse-to-fine подбором гиперпараметров (`max_features='log2'`, `max_depth=5`, `criterion='gini'`, `min_samples_split=9`, `min_samples_leaf=1`) обходит SVM по F1 и по балансу precision/recall.
4. Топ важных признаков указывает, что специализация и географический контекст несут больше информации о поле, чем чисто количественные метрики — что согласуется с реальной неоднородностью гендерного распределения по направлениям подготовки и регионам в IT.
5. Направления для дальнейшего улучшения: oversampling (SMOTE), подбор оптимального порога классификации, дополнительный feature engineering.
